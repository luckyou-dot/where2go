## 2. 当前验证基线（2026-11-24 复跑）

- 语法：21 个业务 JavaScript 文件全部通过语法检查（`new Function` 等价 `node --check`，0 失败；不含本地 `js/map-config.js` 与配置示例）。
- 路由：`#/home`、`#/whereto`、`#/routes`、`#/publish`、`#/buddies`、`#/profile`、`#/spot/:id`、`#/buddy/:id` 均可渲染。
- 数据：`W.Store.listSpots()` 返回 296 条；首页城市下拉 37 项（全部城市 + 36 城）；`W.Store.listUsers()` 返回 5 条。
- 本文件不代表自动化测试通过——仓库没有内置自动化测试框架；需要人工走查。

## 3. 快速冒烟（约 5 分钟）

1. 打开首页：地图渲染（高德/Leaflet/SVG 任一不白屏），城市下拉 37 项，默认广州 25 个地点。
2. 切换「杭州」：列表变为杭州 15 个地点，地图与标题同步。
3. 点「去哪」：自动抽签出结果卡；点「再摇一次」结果变化；点「就去这里」进入详情。
4. 打开 `#/routes`：默认「半日经典」有 4 站、时间轴与示意图；切换「一日漫游」变为 6 站。
5. 打开 `#/publish`：空表单提交出现逐字段错误；填完整可提交并跳详情。
6. 打开「我的 → 护照」：显示打卡统计、城市印章与 6 枚徽章。
7. 刷新页面：点赞/收藏/评论/路线/打卡状态仍在（localStorage `wqwn.v3`）。

## 4. 全量走查清单

### 4.1 首页地图与筛选

- [ ] 地图默认以广州为中心；拖动、缩放正常；单标记点击进入对应 `#/spot/:id`。
- [ ] 聚合标记点击弹出该组地点列表，任选一项进入详情。
- [ ] 地图由高德加载失败时自动回退 Leaflet + OSM；再失败显示纸张色 SVG 示意图，标记仍可点击、页面不白屏。
- [ ] 城市下拉包含「全部城市 / ALL」+ 36 城；切换后地图重新居中、列表只显示该城市地点。
- [ ] 选「广州」可见 25 个地点；「3km」「5km」距离档可逐层收窄/放宽。
- [ ] 搜索框输入关键词回车可过滤；清除按钮恢复全量；中文输入法选词不误触发。
- [ ] 三组筛选 chips 互斥高亮：题材 7 项、娱乐设施 7 项、距离 5 档；组合出空结果显示空态与「清除筛选」。
- [ ] 「大家都在夸」显示 6 条高赞评论，鼠标滚轮横滑、按住拖拽可用，点击进入对应详情。

### 4.2 今天去哪

- [ ] 首次进入自动翻签，约 0.6–0.9 秒后出现结果卡（编号、分类、标题、城市·价格、最高赞评价）。
- [ ] 7 个心情 chips 与 7 个设施 chips 可切换，chip 高亮且 `aria-pressed` 正确。
- [ ] 连点「再摇一次」相邻两次不重复；只剩一个地点时提示「签筒里只剩这一张了。」
- [ ] 「就去这里」进入对应详情，标题一致。
- [ ] 「把这一签，串成一条路线」进入路线页，第一站为当前地点。
- [ ] 返回或切换 tab 再回来保留本次结果与心情；刷新页面重新抽签。
- [ ] `prefers-reduced-motion` 下不播放抽签动画，直接出结果。

### 4.3 路线串点

- [ ] 5 种走法切换后站数分别为 4 / 6 / 4 / 4 / 4，时间轴起点 13:30 / 10:00 / 14:00 / 18:30 / 14:00。
- [ ] 切换城市只使用该城市地点，城市栏显示「N 个地点可串」。
- [ ] 「换一条」路线编号变化、站点组合不同。
- [ ] 「保存这条路线」后「我的路线」出现条目；刷新仍在；「查看」回看顺序；「删除」确认后移除。
- [ ] 从「去哪」带入起点时，路线第一站与抽签地点一致。

### 4.4 发布

- [ ] 只填分类直接提交：名称/分类/地址/坐标/价格处出现红色提示且不创建。
- [ ] 名称 1 字或 41 字被拦截；正常填写（2–40 字）可提交并跳转新地点详情。
- [ ] 「定位」按钮可自动填写地址和经纬度（浏览器允许定位时）；拒绝时提示手动填写。
- [ ] 九宫格选内置图 1–9 张；「添加照片」可多选本地图片、压缩、预览、单张移除；超过 9 张被拦截。
- [ ] 顶部投稿卡标题/分类/城市/价格/首图实时联动。

### 4.5 地点详情

- [ ] 头图约 408px，图片 ≥2 张可横滑，指示点跟随。
- [ ] 四项统计显示评论数 / 浏览量 / 点赞 / 收藏；进入详情浏览量 +1。
- [ ] 点收藏、点赞即时切换图标与数字，刷新后保持。
- [ ] 避雷:无记录地点显示「暂无避雷标记，你来做第一个提醒者」；提交后人数 +1；可修改、可取消。
- [ ] 护照打卡：首次点击 toast 显示第 N 个脚印；再次点击无效；护照页统计同步。
- [ ] 实况：空内容提示「写点什么再发布吧」；1–140 字 + 最多 3 张图可发布；本人可删除；无实况显示空态。
- [ ] 评论：空内容/超 200 字被拦截；正常提交置顶；最多 3 张配图；作者可删除。
- [ ] 所有图片可点开灯箱：滚轮缩放 1×–4×、拖动、双击/复位、×/黑底/Esc 关闭。

### 4.6 搭子广场与详情

- [ ] 搭子列表按日期公告板显示，类型/状态/时间/地点/成员容量齐全；类型筛选与搜索可用。
- [ ] 发起搭子：过去时间、人数 1/21 被拦截；正常发布后出现在广场，成员 1/x。
- [ ] 非自己发起的搭子可申请（留言 + 联系方式）；重复申请 / 已是成员 / 已满员分别提示。
- [ ] 发起人打开自己的搭子可见待审批申请；同意后成员 +1；满员状态变「已满员」。
- [ ] MATCHMAKER 三问完成显示分数、理由和结果卡；「发布同款搭子」预填类型与城市但不自动发布。

### 4.7 我的

- [ ] 头像卡、四项统计、七个分段（发布 / 护照 / 发起 / 加入 / 申请 / 收藏 / 点赞）均可切换。
- [ ] 各分区条目点击跳对应详情；空分区显示占位与去处按钮。
- [ ] 护照分段显示打卡地点 / 到访城市 / 连续天数 / 获得徽章，城市印章可点回地点详情，6 枚徽章显示进度。
- [ ] 「切换演示身份」切换 5 个用户后 Hero 背景随城市变化；「重置演示数据」确认后恢复种子。

### 4.8 持久化、兼容与响应式

- [ ] 发布地点、点赞、收藏、评论、路线、打卡后刷新页面数据仍在；关闭标签页重开仍在。
- [ ] 控制台执行 `localStorage.setItem('wqwn.v3', JSON.stringify({version:2,currentUserId:'u1',users:[],spots:[],buddies:[]}))` 后刷新：不报错、不白屏，缺字段自动补齐。
- [ ] 旧版 localStorage（阶段 33 及以前）刷新后通过 `syncSeedExpansion` 自动补齐 90 个新地点，无空白/重复。
- [ ] 360 / 430 宽无横向溢出；桌面 ≥720px 为居中手机画布；tabbar 固定且可点。

## 5. 数据层检查（开发者）

```js
// 在浏览器控制台执行
W.Store.listSpots().length        // 296
W.Store.listUsers().length        // 5
W.Store.listBuddies().length      // 4
W.Store.listMyRoutes('u1')        // []
W.Store.getPassport('u1')         // 打卡统计与 6 枚徽章
```

- 所有写操作错误码：`INVALID_BUDDY`、`INVALID_ROUTE`、`INVALID_USER` 等，应在视图中转为中文提示。
- `W.Store.reset()` 应恢复 296 地点基线；测试新增内容应通过 `reset()` 清理。

### 5.1 可选数据层冒烟脚本

`node scripts/store-smoke.mjs`：从项目根目录执行，使用 Node `vm` 加载 `js/seed.js` + `js/store.js`，覆盖打卡幂等、passport 统计、live/warn 增删与 reset 等 19 项数据层断言；脚本不依赖浏览器，输出逐项 `ok` 与 `ALL PASS`。这是旧阶段 10 冒烟脚本迁移到 `scripts/` 后的保留版本，当前仍可运行。
