# 出来去哪玩 · 全量测试与修复报告

> **归档说明（2026-11-24）**：本报告对应 2026-11-23 的 206 地点 / 21 城版本，已归档为历史记录；当前版本（296 地点 / 36 城）的测试指南见 [../../testing.md](../../testing.md)。

测试日期：2026-11-23  
测试环境：本地 `python -m http.server 8080`，内置浏览器（430px 手机画布 + 360px 窄屏 iframe），Chrome DevTools 控制台  
测试范围：README 全部 23 个功能测试步骤、数据层 Store API、页面无错误/无横向溢出、关键安全与权限场景

## 一、结论

本轮共发现并修复 19 类问题，其中首页搜索回车失效、首页筛选条丢失、个人中心“点赞”分段崩溃、旧 localStorage 详情页崩溃属于阻断性问题。修复后：

- 19 个 JavaScript 文件全部通过 `node --check`
- 8 个核心页面（首页/去哪/路线/发布/搭子/我的/详情/搭子详情）在 360px、430px 下均无横向溢出、无 page-error、无 console error
- 首页搜索 Enter、分类/娱乐设施/距离筛选、全部城市切换均复测通过
- 测试数据已通过 `W.Store.reset()` 还原为 5 用户 / 206 地点 / 4 搭子 / 560 评论 / 13 打卡 / 0 路线

## 二、关键修复

### 1. 首页搜索（用户原始反馈）
`js/views/home.js`

- 搜索块改为 `<form role="search">`，补 Enter 提交处理
- 增加 `submitSearch()`：实时过滤、toast 结果数、滚动到结果区
- 增加搜索清除按钮 `clearSearch()`、结果数提示、搜索态标题
- Enter 处理加 `e.isComposing || e.keyCode === 229` 守卫，避免中文输入法选词误提交

### 2. 首页筛选条恢复
`js/views/home.js`

视觉重构后分类 chips、娱乐设施 chips、距离 chips 曾丢失。已恢复：
- 按题材：全部 / 美食 / 玩乐 / 自然风景 / 拍照打卡 / 夜生活 / 其他
- 娱乐设施：KTV / 剧本杀 / 密室逃脱 / 桌游 / 电玩城 / 影院 / Livehouse
- 距离：500m / 1km / 3km / 5km / 不限
- 两行互斥高亮，空结果有“清除筛选”

### 3. “全部城市”修复
`js/views/home.js`

- `setCity('all')` 不再把距离限制在 3km
- 选择“全部城市”时 Location session 的 city 置空，避免下次渲染被旧城市覆盖
- 新增 `mapCityName()`：展示显示“全部城市”，地图/高德跳转仍使用广州中心
- Hero、附近标题、图例、高德搜索文案在“全部城市”下正确显示

### 4. 个人中心“点赞”分段崩溃
`js/views/profile.js`

`buildSection('liked')` 曾只放标题后直接结束，`appendChild(undefined)` 导致整页加载失败。已补：
- `return wrap`
- 点赞地点列表、封面、分类徽章
- 空态“还没有点赞过地点”和“去首页逛逛”

### 5. 旧 localStorage 兼容
`js/store.js`

当旧数据 `users: []` 时，`getCurrentUser()` 返回 null，详情页读取 `me.id` 崩溃。现在初始化时：
- 用户表为空则回退到种子用户并修正 `currentUserId`
- 补持久化，避免每次刷新重复修复

### 6. 数据层权限
`js/store.js`、`js/views/detail.js`、`js/views/buddyDetail.js`

- `deleteComment(spotId, commentId, userId)` 校验作者
- `respondApply(buddyId, applyId, action, userId)` 校验发起人
- `deleteLivePost`、`deleteRoute` 将 userId 变为必填并校验所有权

### 7. 其他修复
- `js/views/publish.js`：内置图库/上传路径统一限制最多 9 张，上传中禁用添加入口
- `js/store.js`：种子扩城迁移只替换种子评论（id 形如 `c1`），不再覆盖用户新增评论照片
- `js/views/detail.js`：补齐佛山/深圳/北京/长沙城市中心，修复北京地点显示 1890km 的问题
- `js/ui.js` + `js/views/routes.js`：用户文本不再被当作 HTML 解析，封堵标题/评论 XSS；图标、头像改为 DOM 节点
- `js/ui.js` + `js/map.js`：高德导航 URI 复用 WGS-84 → GCJ-02 转换
- `js/map.js`：SVG 降级地图补齐四城地名
- `js/views/routes.js`：回到推荐时清空临时起点；路线示意图起点与首站重合时去重
- `js/views/profile.js`：分段“足迹”恢复为 README 要求的“护照 / PASSPORT”
- `js/views/buddyDetail.js`：修复“2小时前前提交”
- `js/store.js`：`addComment` 增加 1–200 字数据层校验；`addBuddy` 对 1/21 等非法人数抛出 `INVALID_BUDDY`
- `js/views/routes.js`：路线页地点/城市数改为动态计算，城市栏计数随切换刷新

### 8. 评论配图与帖子图片去重（本轮追加）
`js/review-photos.js`、`js/store.js`、`js/views/detail.js`

- 新增独立 `review-photos/` 评论图库：70 张按分类从百度图片搜索结果采集的实景图，文件说明见 `review-photos/CREDITS.md`
- 种子评论（`c1`、`c23` 等）的配图统一换成该地点所属分类的评论图库，并且排除该地点的 `cover` / `images`，避免帖子图和评论图重复
- 评论输入框的“点选图片”改为评论图库，帖子内置图库仍使用 `js/ui.js` 的 `UI.pics`，两处图源分离
- 旧 localStorage 数据在 `Store.init()` 时自动迁移：206 个地点、305 条有图评论全部替换为评论图，重复数从 175 个资源引用降为 0；用户新增评论图片不受影响
- 验证：`W.ReviewPhotos.forSpot()` 对 206 个地点返回的配图均不与封面/图集相交；评论图 200 加载正常

### 9. 地图标记跳转与底图干扰（本轮追加）
`js/views/home.js`、`js/map.js`、`css/style.css`

- 单个编号标记点击后直接进入对应地点详情，不再只滚动卡片
- 聚合标记点击后打开该组地点列表，可选择任意地点进入详情
- 高德底图移除 `point` 图层，只保留道路/建筑等基础底图，避免把底图商家/学校名误认成应用地点
- 复测：广州“不限”距离档下 “9 个地点” 聚合组可列出 9 个地点并跳转；单个标记跳转 `#/spot/s46` 成功；无 console error
